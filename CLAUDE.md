## Communication

- Always reply to the user in correct, clear Arabic, formatted to read well right-to-left (RTL).
- Start every line and bullet with an Arabic word; never open a line with an English term, number or link.
- Put code, file paths, commands, URLs and English technical names in `backticks` or on their own line.
- Use Arabic punctuation (، ؛ ؟). Keep product/service names (GitHub, Supabase, WhatsApp, Next.js) as they are.
- Code, comments and commit messages stay in English.
