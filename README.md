# Sharjah Drug Store

Website and dashboard for **Sharjah Drug Store L.L.C.** (مستودع الشارقة للأدوية), a medicine warehouse in Sharjah since 2003. Partner companies sell their own products through the warehouse; every product shows its company and links to the company's profile.

- **Public site** in English (`/en`, default) and Arabic (`/ar`, RTL): home, all products with company/category filters and search, product pages, company profiles, cart.
- **Ordering via WhatsApp**: the cart sends one message, grouped by company, to the warehouse number set in the dashboard. Wholesale prices and prescriptions are also requested on WhatsApp.
- **Dashboard** (`/dashboard`, login at `/login`):
  - *Warehouse admin*: products, companies, categories, Best Selling order, offer banner, site settings (WhatsApp number, contact info, free-delivery amount), accounts, newsletter subscribers.
  - *Company account*: only its own products and company profile. This is enforced by Postgres row-level security and storage policies, not just the UI.

## Stack

Next.js 16 (App Router, Turbopack) · Tailwind CSS 4 · Supabase (Postgres, Auth, Storage, one Edge Function).

## Run locally

```bash
npm install
cp .env.example .env.local   # Supabase URL + publishable key
npm run dev
```

Open http://localhost:3000 (redirects to `/en`).

## Project layout

| Path | What |
| --- | --- |
| `src/app/(site)/[lang]/` | Public pages (one root layout per language) |
| `src/app/(admin)/` | `/login` and `/dashboard/*`; server actions in `dashboard/actions.ts` |
| `src/lib/i18n.ts` | All English/Arabic interface text |
| `src/lib/data.ts` | Public data queries (anonymous Supabase client, cached pages) |
| `src/proxy.ts` | Adds the language prefix; keeps dashboard sessions fresh |
| `supabase/migrations/` | Schema, RLS and storage policies |
| `supabase/functions/manage-users/` | Admin-only account creation / password reset / delete |
| `supabase/seed.sql` | Demo catalog (5 companies × 10 products) |
| `scripts/` | Demo data source and image generator (`node scripts/generate-images.mjs`) |

Public pages are cached and refresh every 5 minutes; anything saved in the dashboard refreshes the site immediately.

## Demo content

The 5 companies, 50 products and all product/company images are **placeholders** generated by `scripts/`. Replace them from the dashboard (images upload to the Supabase `media` bucket).
